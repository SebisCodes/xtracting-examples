Connection colours

About this page

Connection types are free text from the extraction, so they are grouped: one colour per group, on the map and in the graph. A type nobody has assigned takes the colour of the fallback group.

The list on the left is one line per group, counting the connection types of this project. Open one to change its colour, its name or what belongs in it. A new group starts empty; types are assigned to it in the table on the right.

The table on the right lists every connection type in this project, in every language - one row per spelling, so “Supplier” and “Lieferant” are assigned separately and can still go to the same group.

A GROUP IS ALSO A BUCKET. Searching for a group’s name in any view searches every connection type in it, exactly as a bucket does for entities or types - so connection types are grouped here and nowhere else. That is why the Buckets page has no connection-type kind: one thing grouped in two places would sooner or later be grouped two different ways.

{#- The add form is the FIRST thing in this column, not the last. Under the list would be tidy and wrong: eleven groups of three fields each are three screens, and "add a group" would be three screens of scrolling away. A customer with twenty type families would have five. The list under it is collapsed for the same reason - one line per group, opened when there is something to change - so the whole column is a page of summaries and the work is at the top. -#}
