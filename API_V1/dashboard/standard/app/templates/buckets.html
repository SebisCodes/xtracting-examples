{#- Buckets: the values that are searched as one. Buckets are not kept in the browser - per browser they would be never shared, lost with the cache, and invisible to the server that runs the query. They are rows in the `dashboard` schema, so a bucket a colleague made is a bucket everybody searches with, and app/scope.py expands a term through it on every view. A bucket has a KIND. It began as "several spellings of one entity" and it is the same problem everywhere else: an archive built from free text calls one type, one place, one unit several names, and in a bilingual archive it does so twice over - "Company" and "Unternehmen" are two rows in entity_types, so every type search and every "by type" chart splits one thing in half until somebody says they are the same. The kind selector is why this is one page and not nine. Three things this page has to make obvious, because they are what people get wrong about buckets: 1. WHAT A MEMBER IS depends on the kind. For an entity it is a NAME AND A TYPE - "Apple (Company)" belongs in the Apple bucket and "Apple (Fruit)" does not, and the type is the only thing that tells them apart. For every other kind it is a plain value out of that kind's vocabulary, so there is no type field at all. 2. WHAT THE BUCKET ACTUALLY MATCHES, per language. Members are spelled in one language and entity ids are shared by the translations of a task, so an English member usually reaches the German rows as well - "usually" is exactly why the number is on screen (from /api/buckets/resolve) instead of being assumed. For a type bucket it is the whole point: "Company" reaches the English rows and "Unternehmen" the German ones, and only both together cover the project. 3. A VALUE BELONGS TO ONE BUCKET OF ITS KIND. The suggestion list says which bucket a value is already in rather than hiding it - a value in two buckets would make one term resolve to two groups and only one of them could win. Connection types are deliberately absent: they are grouped on the Connection colours page, and a search treats a colour group exactly as it treats a bucket.
