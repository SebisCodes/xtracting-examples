About this page

The Xtracting projects the crawler's keys open, and the keys of each.

Every watchlist collects into one project. The list here is what the crawler found by asking each key in its own configuration which project it belongs to - so a project appears once a key for it works, and not before.

Deleting a project removes its watchlists and their rules. It does not touch the archive: what was already collected stays, and the project keeps appearing in the selector at the top of every view.
