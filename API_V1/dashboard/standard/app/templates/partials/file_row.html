{#- The two row shapes of the "Files found" dialog. THE TWO COLUMNS ARE TWO DIFFERENT IDEAS, and the markup keeps them apart on purpose: a type row is a standing rule - "send every PDF of this source, up to 25 MB" - and a file row is one exception to it, about one address found in the sample. Mixing them into one list is what makes people tick a hundred files by hand every time the site publishes a new one. A file that cannot be sent as text (a scan without a text layer, a file that is too large, something served as a PDF that is not one) is shown with its reason and no tick box: there is nothing to decide about it. -#}
