Map

About this page

Where an entity and the entities around it are, and how they are connected.

Object searches for one thing: an entity, or a bucket, whose members are all drawn.

Type searches for an event type: every entity the events of that kind are about is drawn on the map, with the same levels and the same connections.

Group by decides what a node is. Entities draws one per entity. Buckets draws one per bucket, so "Germany" is a single node holding everything you gave it - and an entity that belongs to two buckets is drawn in both, because a connection to it really is a connection to each of them.

Level 1 is what the term is directly connected to; level 2 adds what those are connected to, and so on.

The pin of the entity that was searched for is drawn in the accent colour and marked “searched”; the pins around it are grey. Every pin's tip stands on the coordinate the archive has for it.

The two checklists beside the map filter what is drawn: connection types for the lines, location types for the pins. Each has a box that narrows the list and buttons for all and none.

Scrolling over the map zooms it; the + and − buttons do the same.
